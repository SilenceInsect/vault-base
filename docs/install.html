阶段 0

Clone 公开仓库

产出：本机拿到脱敏后的 vault-base 源码

仓库公开、不含真实主机 / 密码 / 组私有目录。凭据与组清单只在本机生成。

0.1

Clone 到临时目录或直接进 common 仓

人工

0.2

确认 Python

人工

阶段 1

common-skills-repo + IDE 联接

产出：一份真相源 + Cursor/Claude/Codex 联接

真相源固定为 ~/common-skills-repo/vault-base（可用环境变量 COMMON_SKILLS_REPO 覆盖仓根）。 各 IDE 的 skills 目录只做 junction / 联接，禁止各拷一份再分叉。

1.1

初始化 common 仓并建 IDE 联接

可自动

python %SKILL%\scripts\common_skills_repo.py link --skill vault-base --ides cursor,claude,codex --backup-existing

阶段 2

安装物料清单（引导提问）

产出：teams/<type>/<name>/install-inventory.yml

其他组成员安装时，skill 必须先引导提问补齐清单，再跑 env_ensure。 组目录默认 Git 忽略，不会随公开仓泄露。

2.1

init → missing → 逐项填写

可自动人工答 
set SKILL=%USERPROFILE%\common-skills-repo\vault-base
python %SKILL%\scripts\install_inventory.py init --id "<team-type>:<team-name>"
python %SKILL%\scripts\install_inventory.py missing --id "<team-type>:<team-name>"
python %SKILL%\scripts\install_inventory.py validate --id "<team-type>:<team-name>"

英文短名（清单内带中文注释）：

短名含义
local_only仅本地 Vault
local_then_shared先本地后共享（推荐）
shared_full直接共享全量
unknown / requested / done / blocked协调项状态
密码位置 清单里密码字段留空或写 <in_secrets>；真实密码只进 references/vault/_kb/secrets.local.json（已在 .gitignore）。
Windows 路径写法（历史阻断） 禁止 path: "C:\Users\..."（双引号 + 反斜杠会触发 YAML \U 转义解析失败）。 请用正斜杠或单引号：path: 'C:/Users/.../common-skills-repo'。 install_inventory.py init 已自动按此规则写入。

4.2

只读探测

可自动 
python %SKILL%\scripts\env_probe.py --json

关注：Redis 是否支持 Stream、AOF / requirepass、MySQL 版本与字符集、同实例其他库数量（影响 DDL 评估）。

R4 身份回读 不能只判断「连接没抛错」；必须回读实际连接身份。连错身份却仍写共享 Redis，会导致发号/缓存污染。

阶段 5.5

安装门禁（必跑）

产出：I1–I8 无 BLOCKER

readiness_gate 只保证连通与本地 Vault 骨架； 不能证明共享写入适配层可用。共享开启后必须再跑 install_gate.py --require-shared。

5.5.1

执行安装门禁

可自动阻塞 
python %SKILL%\scripts\install_gate.py --id "<team-type>:<team-name>" --require-shared --json
项检查什么历史阻断 / 修复
I1IDE LINK → common 仓common_skills_repo.py link
I2物料清单 YAML 可解析Windows 路径用正斜杠/单引号
I3MySQL 表结构 = DDL执行 ddl_mysql57.sql；禁止旧 meta_json / vault_events
I4vault_consume 可导入redis_conn 从 vault_secrets 导入
I5list_pending 可执行MysqlVaultStore 对齐 pending 表字段
I6store.search 可执行查 shared_vault_main 且 status=active
I7Redis PING + LIST3.2 无 Stream，用 LIST 后端
I8空队列 BRPOP 不抛超时socket timeout ≥ BRPOP 等待
I9prefixCache vault:c:与队列键分离；SET EX/GET/DEL

可选 Laya 本地门控（非门禁）：默认关闭。先 pip install "laya[serve]" && laya-serve。 冒烟：python %SKILL%\scripts\laya_client.py share-gate --mock --candidate-shared --title "团队规范" --question "如何沉淀？" --answer "走 vault_dump 再审核"。 微调导出：laya_export_dataset.py --seed-only。契约见 references/laya.md；永不因 Laya 直接 approve。

预期ready=true，blockers=[]。有 BLOCKER 时禁止宣称共享可写，先按 fix 字段修复。
