一站式（推荐，一条命令）： git clone → python scripts/install_all.py （向导只决策一次并写入 install-choices.json；内部自动 link / secrets / 七阶段 / MCP）

断档续跑：还是 python scripts/install_all.py （读上次 choices，不再提问）。重做决策加 --redecide。

clone 之后你只拥有「源码 + 脚本 + 文档」；联接、依赖、库表、凭据、skill 注入都不会自动发生。

一条主链：clone 只是第 0 步 → CLI 装底座 → 改业务 skill → 任务内五步；MCP 只替换「怎么调工具」，不替换协议。

端到端主流程

按时间顺序阅读；琥珀色卡片为硬门禁，未通过则禁止共享写入。

A0

git clone（仅拿到源码，≠ 安装完成）

必要但不充分

Clone 到 ~/common-skills-repo/vault-base。此时还没有：IDE Skill 联接、pip 依赖确认、secrets、库表、业务 skill 注入。

git clone https://github.com/SilenceInsect/vault-base.git ~/common-skills-repo/vault-base
A1

一站式 CLI：install_all

推荐

一条命令串起：IDE link → secrets 落位 → bootstrap 清单 → 七阶段 resume --execute → 可选 MCP。内部同意门仍在；--yes 才自动批准 pip/DDL/adapt。

link→ secrets→ 1…6 phases→ MCP 
python scripts/install_all.py
# 续装 / 断档：同一条，不再决策
python scripts/install_all.py
G

门禁：readiness + install_gate

必过

有 BLOCKER → 中止。共享写入看 capability.can_write_shared；勿只看 readiness 绿灯，须过 I1–I9。

python scripts/readiness_gate.py --fix --json
python scripts/install_gate.py --id test-team:amrd-test --require-shared --json
B

适配业务 Skill（单点注入）

adapt

只改目标 skill 的 SKILL.md（marker 路由节）。hooks / rules / preflight / sediment 全在 vault 侧，卸载可快摘。

python scripts/skill_vault_adapt.py scan --json
python scripts/skill_vault_adapt.py adapt --skill-id <id>
# 或 --all
C

Agent

在 Cursor 中打开已适配 skill（或 /skill-name）。Agent 须走召回 → 前置物料 → 逐问 → 沉淀 → 持久化；成功后把 【金库提示】 贴进 Chat。

2

3

C. 日常使用（Agent 视角）

  1. 用户触发已适配 skill（如 /git-workflow）。
  2. 先 readiness（有 BLOCKER 则停；共享写入看 can_write_shared）。
  3. pre_task_recall → 把 【金库提示】 贴进 Chat。
  4. preflight missing → 一次一问 → write-field，直到 missing 空。
  5. 执行业务任务；过程中/结案 sediment + dump；再贴金库提示。
  6. 候选共享：enqueue → MySQL pending → 人审 → Redis；私有保持 private。
检索叠读顺序 技能索引 → 共享金库（cache→MySQL）→ 本地 Vault → 领域库（若有）→ 资料原文 → 才向用户提问。P0/P1 禁止把默认读源改成公共库。
